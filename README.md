# Vornix Frontend

Next.js 14 App Router frontend scaffold for the Vornix fintech SaaS platform.

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/`
- `/login`
- `/dashboard`
- `/dashboard/evaluation`
- `/dashboard/account`
- `/admin`
